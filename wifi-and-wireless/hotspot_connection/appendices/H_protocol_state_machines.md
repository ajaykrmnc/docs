### H.2 SAE State Machine

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         SAE STATE MACHINE                                    │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│                              ┌──────────────┐                                │
│                              │   NOTHING    │                                │
│                              └──────┬───────┘                                │
│                                     │                                        │
│                                     │ Auth request received                  │
│                                     ▼                                        │
│                              ┌──────────────┐                                │
│                              │  COMMITTED   │◄─────────────────────┐         │
│                              └──────┬───────┘                      │         │
│                                     │                              │         │
│                                     │ Send Commit                  │         │
│                                     │ (scalar, element)            │         │
│                                     ▼                              │         │
│                              ┌──────────────┐                      │         │
│                              │   WAITING    │                      │         │
│                              └──────┬───────┘                      │         │
│                                     │                              │         │
│                                     │ Receive peer Commit          │         │
│                                     │ Compute shared secret        │         │
│                                     ▼                              │         │
│                              ┌──────────────┐                      │         │
│                              │  CONFIRMED   │                      │         │
│                              └──────┬───────┘                      │         │
│                                     │                              │         │
│                                     │ Send Confirm                 │         │
│                                     │ (send-confirm, confirm)      │         │
│                                     ▼                              │         │
│                              ┌──────────────┐                      │         │
│                              │   WAITING    │                      │         │
│                              │  (confirm)   │                      │         │
│                              └──────┬───────┘                      │         │
│                                     │                              │         │
│                                     │ Receive peer Confirm         │         │
│                                     │ Verify confirm               │         │
│                                     ▼                              │         │
│                              ┌──────────────┐                      │         │
│                              │  ACCEPTED    │                      │         │
│                              └──────┬───────┘                      │         │
│                                     │                              │         │
│                                     │ PMK = KDF(K, ...)            │         │
│                                     │ PMKID = hash(...)            │         │
│                                     ▼                              │         │
│                              ┌──────────────┐                      │         │
│                              │   SUCCESS    │                      │         │
│                              └──────────────┘                      │         │
│                                                                              │
│  Error Handling:                                                             │
│  ┌─────────────────────────────────────────────────────────────────────┐    │
│  │ • Anti-clogging token required → Send token, retry                 │    │
│  │ • Invalid scalar/element → Reject, return to NOTHING               │    │
│  │ • Confirm mismatch → Reject, return to NOTHING                     │    │
│  │ • Timeout → Retry or return to NOTHING                             │    │
│  │ • Max retries exceeded → Return to NOTHING                         │    │
│  └─────────────────────────────────────────────────────────────────────┘    │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘
```
