### Key Components

| Component | Description |
|-----------|-------------|

## Device Telemetry

### Device Performance Record

The AP collects system performance metrics at regular intervals:

```c
typedef struct {
  S_UINT32 i_min_ap_latency;
  S_UINT32 i_max_ap_latency;
  S_UINT32 i_sum_ap_latency;
  S_UINT32 i_avg_ap_latency;
  S_UINT32 i_packet_count;
  ethInfo64_t ethInfo[ETH_PORTS_MAX];
  u_int16_t min_cpu_util;
  u_int16_t max_cpu_util;
  u_int16_t avg_cpu_util;
  u_int16_t min_free_mem;
  u_int16_t max_free_mem;
  u_int16_t avg_free_mem;
} DevicePerRec_t;
```

### System Performance Model

```tac
SystemPerf : Tac::Type() : Tac::Nominal {
cpuUtilization : array F32[ cpuCore ];
freeMemory : F32;
availableMemory : F32;
}

DeviceTelemetry : Tac::Type( name ) : Tac::Entity {
systemPerf : SystemPerf;
}
```

### Device Telemetry Collection

The Go-based telemetry collector:

```go
func computeAndPushDeviceTelemetry(inputStats []float32, memUsed, memAvaliable float32) {
  // Collects CPU utilization per core
  // Calculates memory usage percentages
  // Buffers data points for averaging
  // Writes to ArDS based on configured interval
}
```

### Telemetry Intervals

| Parameter | Description |
|-----------|-------------|
| `DeviceIntervalSecs` | Device telemetry collection interval |
| `PeriodicTelemetryConf.Enabled` | Enable/disable periodic telemetry |
| `bufferSize` | Number of data points to buffer before averaging |

## Radio Statistics

### Radio Telemetry Record

```c
typedef struct {
  MACADDR macaddr;           // MAC address of monitor VAP
  S_UINT8 config_radio_id;   // Radio ID as in ap.conf
  S_UINT32 rx_data_frame;    // Received data frames
  S_UINT32 rx_mgmt_frame;    // Received management frames
  S_UINT32 rx_ctrl_frame;    // Received control frames
  S_UINT32 rx_retries;       // Receive retries
  S_UINT32 tx_data_frame;    // Transmitted data frames
  S_UINT32 tx_mgmt_frame;    // Transmitted management frames
  S_UINT32 tx_ctrl_frame;    // Transmitted control frames
  S_UINT32 tx_retries;       // Transmit retries
  S_UINT64 data_bytes_to_dev;   // Bytes sent to device
  S_UINT64 data_bytes_from_dev; // Bytes received from device
} RadioTelemetryRec_t;
```

## Data Formats

### CSV Format

Used for simple tabular data export:

```csv
mac,rssi,timestamp
E4:D1:24:A0:47:60,-64,1704825600
E4:D1:24:A0:47:61,-72,1704825600
```

### JSON Format

Used for structured data with nested objects:

```json
{
"lanMac": "E4:D1:24:A0:47:60",
"ts": 1704825600,
"dataArray": [
{"mac": "AA:BB:CC:DD:EE:FF", "rssi": -64, "time": 5}
]
}
```

### Protobuf Format

Binary serialization for efficient transport:

```c
int SendClientTelemetryRec(ClDevTelemetryRec* perfData) {
  // Serialize using protobuf
  size_t len = cl_dev_telemetry_rec__get_packed_size(perfData);
  cl_dev_telemetry_rec__pack(perfData, buffer);
  // Send using spectra protocol
  Send_Protobuf_Record(packet, packet_len, RELIABLE);
}
```

## ArDS (Arista Data Store)

### Overview

ArDS is the central data repository on the AP for storing and retrieving telemetry and configuration data.

### Initialization

```c
// Setup dependencies of ArDS thread and then start it.
ards_init(&attr);

// Queue sensor configuration to ArDS
ards_enqueue_msg(ARDS_SENSOR_CONF_MESSAGE, &senConfArds, sizeof(senConfArds));
```

### Writing Device Telemetry

```go
func writeDeviceTelToArDS(avgCPU []float32, avgMemUsed, avgMemAvailable float32) {
```

| Message Type | Description |
|--------------|-------------|
| `ARDS_SENSOR_CONF_MESSAGE` | Sensor configuration |
| `ARDS_DEVICE_TELEMETRY` | Device performance data |

## Sensord Threads

The sensord daemon runs multiple threads for data collection:

```c
static threaddef_t g_threads[] = {
  {0, "PseudoMAC", sensor_pmac_init, ...},
  {0, "PriDevLinkMon", linkmon, ...},
  {0, "TimerQueue", timer_queue_thd, ...},
  {0, "Collector", main_collector, ...},
  {0, "EvtHandlerTh", wireless_events_handler, ...},
  {0, "SensorStatus", sensor_status, ...},
};
```

### Thread Capabilities

| Capability | Description |
|------------|-------------|
| `CAPABILITY_SENSOR` | Full sensor mode |
| `CAPABILITY_VLANPI` | VLAN PI mode |
| `CAPABILITY_SENSOR_ND_COMBO` | Combined sensor mode |
