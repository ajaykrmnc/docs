# sk_buff — The Linux Kernel Socket Buffer: Complete Reference

> The most important data structure in the Linux networking stack

---

## Overview

`struct sk_buff` (socket buffer) is the fundamental data structure used by the Linux kernel to represent network packets. Every packet — whether received from a network interface, generated by a local process, or being forwarded — is represented by an `sk_buff`. Understanding this structure is essential for kernel networking development, driver writing, performance optimization, and systems debugging.
