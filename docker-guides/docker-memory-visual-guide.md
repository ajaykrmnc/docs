## 3. Memory vs Swap Relationship

```
Example: --memory="6g" --memory-swap="8g"

┌─────────────────────────────────────────────────────────────┐
│ Total Memory + Swap: 8GB                                    │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  RAM (Physical Memory): 6GB                                 │
│  ┌──────────────────────────────────────────────────────┐   │
│  │                                                      │   │
│  │  Fast access (nanoseconds)                           │   │
│  │  Stored in physical RAM                              │   │
│  │                                                      │   │
│  └──────────────────────────────────────────────────────┘   │
│                                                             │
│  Swap (Disk-based): 2GB (8GB - 6GB)                         │
│  ┌──────────────────────────────────────────────────────┐   │
│  │  Slow access (milliseconds)                          │   │
│  │  Stored on disk                                      │   │
│  └──────────────────────────────────────────────────────┘   │
│                                                             │
└─────────────────────────────────────────────────────────────┘

Speed Comparison:
RAM:  1 nanosecond   ████████████████████████████████████████
Swap: 1 millisecond  ████ (1,000,000x slower!)
```

## 5. Process Memory (VSZ vs RSS)

```
Process: clangd

Virtual Memory (VSZ): 920MB
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  Actual RAM (RSS): 451MB                                    │
│  ┌──────────────────────────────────────────────────────┐   │
│  │ • Code:        50MB                                  │   │
│  │ • Data:       300MB                                  │   │
│  │ • Stack:        1MB                                  │   │
│  │ • Shared Libs: 100MB                                 │   │
│  └──────────────────────────────────────────────────────┘   │
│                                                             │
│  Allocated but not used: 469MB                              │
│  ┌──────────────────────────────────────────────────────┐   │
│  │ • Memory-mapped files                                │   │
│  │ • Reserved address space                             │   │
│  │ • Swapped out pages                                  │   │
│  └──────────────────────────────────────────────────────┘   │
│                                                             │
└─────────────────────────────────────────────────────────────┘

VSZ = What process thinks it has (virtual)
RSS = What process actually uses in RAM (physical)
```

## 7. OOM Killer Decision Tree

```
                    ┌─────────────────────┐
                    │ Memory Limit        │
                    │ Reached!            │
                    └──────────┬──────────┘
                               │
                               ▼
                    ┌─────────────────────┐
                    │ Can free cache?     │
                    └──────────┬──────────┘
                          │         │
                         YES       NO
                          │         │
                          ▼         ▼
                    ┌─────────┐  ┌──────────────────┐
                    │ Free    │  │ Invoke OOM       │
                    │ Cache   │  │ Killer           │
                    └─────────┘  └────────┬─────────┘
                                          │
                                          ▼
                              ┌───────────────────────┐
                              │ Calculate OOM Scores  │
                              │ for all processes     │
                              └───────────┬───────────┘
                                          │
                                          ▼
                    ┌─────────────────────────────────────┐
                    │ Process Scores:                     │
                    │                                     │
                    │  node (Auggie):    850 ← Highest   │
                    │  clangd:           720             │
                    │  nvim:             300             │
                    │  bash:             120 ← Lowest    │
                    └───────────┬─────────────────────────┘
                                │
                                ▼
                    ┌─────────────────────┐
                    │ Kill process with   │
                    │ highest score       │
                    │ (node/Auggie)       │
                    └──────────┬──────────┘
                               │
                               ▼
                    ┌─────────────────────┐
                    │ Memory freed?       │
                    └──────────┬──────────┘
                          │         │
                         YES       NO
                          │         │
                          ▼         ▼
                    ┌─────────┐  ┌──────────────┐
                    │ Done    │  │ Kill next    │
                    │         │  │ process      │
                    └─────────┘  └──────────────┘
```
